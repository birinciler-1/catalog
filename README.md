# كتالوج المندوب (PWA)

تطبيق يعمل على الآيباد بدون إنترنت: بحث فوري، تفاصيل المنتج، مشاركة صورة بالسعر عبر واتساب، وتصدير PDF.
مصدر البيانات الوحيد = ملفات الإكسل. غيّر الإكسل ← تتحدث الأسعار عند كل المندوبين.

## هيكل المشروع
```
excel/         ملف إكسل لكل شركة (اسم الملف = اسم الشركة، مثل: دنيا.xlsx)
raw_images/    صور المنتجات الأصلية (بدون الشرائح البرتقالية)، اسم الصورة = كود المادة: 01010.png
data/          products.json (يُولَّد تلقائياً)
images/        thumbs و full (تُولَّد تلقائياً بحجم صغير)
assets/logo.png  (اختياري) شعارك، يظهر أعلى صورة المشاركة
```

## التشغيل لأول مرة
1. أنشئ مستودعاً على GitHub وارفع كل محتويات هذا المجلد (Add file ← Upload files).
2. Settings ← Pages ← Source: `Deploy from branch` ← الفرع `main` والمجلد `/ (root)`.
3. بعد دقيقة يظهر الرابط `https://اسمك.github.io/اسم-المستودع/`.
4. على الآيباد: افتح الرابط في Safari ← مشاركة ← «إضافة إلى الشاشة الرئيسية».
5. افتح التطبيق وأنت متصل ← ⚙ الإعدادات ← «تحميل كل الصور» (مرة واحدة). بعدها يعمل بلا إنترنت.

## تغيير الأسعار أو الأسماء (كل يوم)
1. عدّل ملف الإكسل (نفس الأعمدة: اسم المادة، كود المادة، باركود المادة، عدد الباقي، عدد التعبئة، سعر المفرد، سعر الكارتون).
2. ارفعه إلى مجلد `excel/` في GitHub (يستبدل القديم).
3. خلال دقيقة تعمل الأتمتة (تبويب Actions) وتحدّث `data/products.json`.
4. المندوب يفتح التطبيق وهو متصل ← تتحدث الأسعار تلقائياً (أو ⚙ ← تحديث الأسعار الآن).

## إضافة منتجات جديدة
أضف صفاً في الإكسل + ارفع صورة باسم الكود إلى `raw_images/`. القائمة `reports/missing_images.txt` تُظهر المواد التي لا صورة لها.

## ملاحظات
- أسماء الصور: يقبل `01010.png` أو `1 - 01010.png`. إن تكررت الأكواد بين شركات ضع الصور في مجلد باسم الشركة: `raw_images/دنيا/01010.png`.
- الأكواد الرقمية القصيرة تُكمَّل بأصفار حتى 5 خانات (748 ← 00748). الأسعار تُقرأ كأرقام صحيحة (7750).
- المستودع الأصلي للصور قد يكبر (حد GitHub الموصى به 1GB). إن كبر: شغّل `python tools/convert.py` على حاسوبك وارفع مجلدي `data` و`images` فقط.
- GitHub Pages المجاني يتطلب مستودعاً عاماً، أي أن الرابط (بما فيه سعر الكارتون) متاح لمن يعرفه. للخصوصية استخدم Cloudflare Pages مع Access أو Netlify بكلمة سر.
- وضع عرض الزبون (⚙) يُخفي سعر الكارتون والكمية والباركود.
